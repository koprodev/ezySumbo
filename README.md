# ezy SumBo

A Windows utility that keeps a selected window or region visible in a floating, always-on-top mirror.

Windows용 창·영역 미러링 도구입니다. 필요한 화면을 작은 창으로 띄워 작업 중에도 확인할 수 있습니다.
